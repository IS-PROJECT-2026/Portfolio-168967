
# Personal Portfolio Website

The portfolio showcases my profile, skills, projects, and contact information.

## About the Project

This project is a simple personal portfolio designed to provide information about me, my technical skills, and projects I have worked on.

## Features

- Personal profile and introduction
- About Me section
- Skills section
- Projects section
- Project filtering by category
- Responsive layout for desktop and mobile devices
- Mobile navigation menu
- Contact section
- GitHub Pages deployment

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages
